
# Video Journal Portfolio PRO

Includes:

- Dark / Light theme toggle (saved in browser)
- Category filtering (Photo / Video / Design)
- Modular CSS variables
- Responsive grid layout
- GitHub Pages ready

---

## Deploy

1. Create GitHub repo
2. Upload files
3. Settings → Pages → main branch
4. Done

---

## Add New Categories

In each entry:

<article class="entry" data-category="photo">

Change "photo" to:
- photo
- video
- design

Then add matching filter button:

<button data-filter="newcategory">New</button>

---

## Customize Theme Colors

Edit theme variables in css/styles.css:

html[data-theme='dark']
html[data-theme='light']
